# Projeto de Estudo: HttpClientFactory

Este projeto foi criado com o objetivo de explorar e aprender sobre o `HttpClientFactory` no contexto de desenvolvimento de aplicações .NET. O `HttpClientFactory` é uma funcionalidade poderosa que facilita a criação e o gerenciamento de instâncias de `HttpClient`, ajudando a evitar problemas comuns como o esgotamento de soquetes e melhorando a performance e a confiabilidade de chamadas HTTP.

## Objetivos do Projeto

- Entender como o `HttpClientFactory` funciona.
- Aprender a configurar e usar o `HttpClientFactory` em uma aplicação .NET.
- Explorar boas práticas para fazer chamadas HTTP em aplicações .NET.
- Evitar problemas comuns relacionados ao uso incorreto do `HttpClient`.
